# minitorch

Сделано как тестовое задание в JetBrains Research.

Запустить обучение (если сохранённая модель отсутствует) и предсказание на train:
	`python3 main.py --num-epochs 2 --seed 137 --model-filename new_model.npz` 

Запустить проверку градиента на случайном сэмпле:
	`python3 main.py --operating-mode gradient-checking`

В настоящий момент реализована простая свёрточная сеть с одним промежуточным линейным слоем на 300 нейронов и LeakyReLu(0.1) активациями.
На тестовой выборке сеть достигает accuracy=0.9346. Обучена модель на 25 эпохах. В train взято 90% выборки, в validation 10% выборки, test отложен отдельно.

## Замечания
* Фреймворк пока что позволяет обучать лишь feedforward сети без skip connections и residual слоёв. Сейчас пока что не реализован полноценный AST для математических выражений. Для него недостаёт возможности делать не только унарные, а ещё и бинарные операции. В таком случае потребуется проталкивание градиента по обеим веткам вычислений. А главное, потребуется хранение информации о вычислениях в forward-слое.
* Чтобы регуляризовать слой в текущем подходе мне требуется в полуручном режиме добавлять regularization loss и градиенты.
* В настоящий момент обработка ведётся одиночными примерами, не батчами. Сэмплы должны быть векторами размерности `(28*28, 1)`. В то же время SGD считает градиент по батчу, а не по отдельному примеру.
